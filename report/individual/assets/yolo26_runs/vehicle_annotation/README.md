# Log train Colab gốc

Các đường validation và confusion matrix trong thư mục này thuộc phiên Colab gốc với thứ tự ID eval chưa khớp schema model. Giữ nguyên làm lịch sử. Các loss train và 50 dòng epoch là log thực tế. Kết quả đúng ID của checkpoint được chọn nằm tại `../vehicle_eval/`, và JSON tổng hợp là `../../model_eval_metrics.json`.
